# 🩺 Diabetes Prediction App

A Machine Learning web application that predicts diabetes with **78% accuracy** using Flask.

## 🚀 Live Demo
Run locally: `http://127.0.0.1:5000`

## 🧠 Tech Stack
- Python, Flask
- Scikit-learn (Random Forest)
- Pandas, NumPy

## 📊 How it works
1. User enters health parameters (Glucose, BMI, Age etc.)
2. Model predicts Diabetes Risk (0/1)
3. Shows result instantly

## 🔧 How to Run
```bash
pip install -r requirements.txt
python app.py
